## TYPOGRAPHY

### Primary Typeface

**Font Family:** Inter, Roboto, or Helvetica Neue (sans-serif)

- **Usage:** Headlines, body text, UI elements, digital communications
- **Characteristics:** Modern, clean, highly legible at all sizes
- **Weight Options:** Light (300), Regular (400), Medium (500), Bold (700), Extra Bold (900)

### Secondary Typeface

**Font Family:** Open Sans, Montserrat, or Lato

- **Usage:** Supporting headlines, subheadings, accent text
- **Characteristics:** Friendly yet professional, excellent screen legibility
- **Weight Options:** Regular (400), Semi-Bold (600), Bold (700)

### Typography Hierarchy

```
H1 (Headlines): 48px, Bold (700), Letter-spacing: -0.5px
H2 (Major Sections): 36px, Bold (700), Letter-spacing: -0.3px
H3 (Subsections): 28px, Semi-Bold (600), Letter-spacing: 0px
H4 (Tertiary): 22px, Semi-Bold (600), Letter-spacing: 0px
Body Text: 16px, Regular (400), Line-height: 1.6
Small Text: 14px, Regular (400), Line-height: 1.5
Caption: 12px, Regular (400), Line-height: 1.4
```

### Typography Guidelines

- Maintain minimum font size of 12px for readability
- Use adequate line spacing (1.5x minimum) for body text
- Limit line length to 60-80 characters for optimal readability
- Use consistent capitalization: sentence case for body text, title case for headings
- Avoid ALL CAPS except for acronyms and short labels
- Ensure sufficient contrast between text and background (WCAG AA standard minimum)

## COLOR PALETTE

### Primary Colors

**Valeo Lime Green**
- HEX: #CCFF00
- RGB: 204, 255, 0
- CMYK: 20, 0, 100, 0
- Usage: Logo primary color, call-to-action buttons, headlines, primary brand expressions

**Valeo Dark Gray/Charcoal**
- HEX: #3D3D3D
- RGB: 61, 61, 61
- CMYK: 0, 0, 0, 76
- Usage: Logo accent bar, body text, secondary information, headers, navigation

**Valeo White**
- HEX: #FFFFFF
- RGB: 255, 255, 255
- Usage: Backgrounds, primary text on dark backgrounds, clean spaces

**Valeo Black**
- HEX: #000000
- RGB: 0, 0, 0
- CMYK: 0, 0, 0, 100
- Usage: Text, strong contrast elements, dark backgrounds with white text

### Secondary Colors

**Light Gray (Neutral Background)**
- HEX: #F5F5F5
- RGB: 245, 245, 245
- Usage: Secondary backgrounds, subtle dividers, card backgrounds

**Medium Gray**
- HEX: #999999
- RGB: 153, 153, 153
- Usage: Disabled states, subtle text, secondary UI elements

**Light Green (Accent)**
- HEX: #E6FF33
- RGB: 230, 255, 51
- Usage: Highlights, interactive elements, secondary emphasis

**Accent Teal**
- HEX: #00A8A8
- RGB: 0, 168, 168
- Usage: Links, secondary CTAs, interactive elements

**Accent Orange**
- HEX: #FF9900
- RGB: 255, 153, 0
- Usage: Warnings, special promotions, emphasis

### Color Usage Guidelines

- **Primary Brand Color (Lime Green):** Reserved for logo and critical brand expressions
- **Headings & Navigation:** Use Valeo Dark Gray or Valeo Lime Green for main content hierarchy
- **Body Text:** Use Valeo Dark Gray or Black for optimal readability
- **Backgrounds:** Primarily white with accent use of light gray
- **Call-to-Action:** Valeo Lime Green with dark gray or black text for maximum contrast
- **Interactive Elements:** Accent Teal for links and secondary actions
- **Status Indicators:** Lime Green for success, Orange for caution, Red for errors
- **Accent Highlights:** Use Light Green for emphasis and call-outs

### Accessibility Requirements

- Maintain 4.5:1 contrast ratio for text elements (WCAG AA)
- Test color combinations for color-blind users
- Never rely solely on color to convey information
- Use patterns or icons in addition to color coding

## LOGO USAGE

### Logo Versions

**Primary Logo:**
- Valeo wordmark with red accent
- Minimum width: 120px
- Clear space: 20px on all sides
- File formats: PNG, SVG (preferred), EPS, PDF

**Horizontal Logo (Full)**
- Logo with tagline "Smart Technology For Smarter Mobility"
- Usage: Headers, large formats, official communications
- Minimum width: 200px

**Horizontal Logo (Compact)**
- Logo with simplified text treatment
- Usage: Navigation bars, document headers
- Minimum width: 120px

**Vertical Logo**
- Stacked version for square/portrait layouts
- Usage: Social media profiles, narrow spaces
- Minimum height: 100px

**Monochrome Logo (White)**
- Single-color white version
- Usage: Dark backgrounds, overlays
- Maintain minimum clear space of 20px

**Monochrome Logo (Dark Gray)**
- Single-color dark gray version
- Usage: Light backgrounds, print applications
- Maintain minimum clear space of 20px

### Logo Placement

- Center logo on white or light background with adequate white space
- Avoid placing logo near page edges (maintain 20px minimum margin)
- Position logo consistently across all applications
- On dark backgrounds, use white or light version only
- Never crowd logo with other graphic elements

### Logo Don'ts

- Do not modify logo proportions or distort the mark
- Do not add special effects, shadows, or gradients
- Do not change colors without approval
- Do not rotate logo (keep horizontal or vertical alignment)
- Do not use low-resolution versions
- Do not place logo directly on busy imagery
- Do not combine logo with competing brand marks
- Do not scale logo below minimum size requirements

## PHOTOGRAPHY & IMAGERY

### Photography Style

**Aesthetic Direction:**
- Modern, clean compositions
- High-quality production values
- Authentic, inclusive representation
- Forward-looking perspective showing innovation and progress
- Emphasis on technology, precision, and human connection

### Photography Guidelines

**Technical Specifications:**
- Minimum resolution: 300 DPI for print, 72 DPI for web
- Aspect ratios: 16:9 (landscape), 3:2 (landscape), 1:1 (square)
- File formats: JPG (web), TIFF (print), PNG (with transparency)
- Color grading: Consistent, warm-to-neutral tones with clear blues and reds

**Subject Matter:**
- Modern vehicles and automotive technology
- Diverse team members in professional settings
- Innovation labs and manufacturing facilities
- Motion and energy suggesting progress
- Close-ups of technology components and innovations
- Urban and natural landscapes suggesting sustainability

**Composition:**
- Use negative space effectively
- Strong focal points with clear subject hierarchy
- Natural lighting preferred; avoid harsh shadows
- Leading lines to guide viewer attention
- Include human elements for connection and relatability

### Imagery Don'ts

- Avoid clichéd stock photos
- Do not use outdated or low-quality images
- Avoid overly stylized or artificial filters
- Do not show poor manufacturing conditions
- Avoid imagery suggesting unsafe practices
- Do not use competing brand vehicles or technology

### Illustration & Iconography

**Icon Style:**
- Minimal, geometric design
- Consistent line weight (2-3px for web)
- Simple, recognizable shapes
- Scalable to any size
- Available in outline and filled versions

**Color Usage in Icons:**
- Primary: Valeo Red, Valeo Blue
- Secondary: Accent colors for emphasis
- Neutral: Dark Gray for secondary information

**Illustration Direction:**
- Geometric and abstract when representing technology
- Flat design (no 3D effects or shadows)
- Limited color palette (2-4 colors maximum)
- Consistent line work and proportions

## WRITING GUIDELINES

### Key Message Framework

**What We Do:**
Valeo designs and manufactures innovative automotive technologies that enable cleaner, safer, and smarter mobility solutions for global automakers and new mobility players.

**Why It Matters:**
Transportation is undergoing a fundamental transformation toward electrification, autonomous driving, and software-defined vehicles. Valeo's technologies are essential to this shift and its positive environmental and social impact.

**How We Deliver:**
Through three core divisions (Brain, Power, Light), cutting-edge R&D, global manufacturing capabilities, and strategic partnerships.

### Messaging Pillars

1. **Innovation Leadership** – Pioneering automotive technologies for future mobility
2. **Sustainability** – Decarbonizing transportation and preserving natural resources
3. **Safety** – Advancing autonomous driving and crash prevention technologies
4. **Reliability** – Proven partner to global automotive manufacturers
5. **Global Presence** – Operating in key markets with deep local expertise

### Writing Style Standards

**Clarity:**
- Use short sentences (15-20 words average)
- Define technical terms on first use
- Avoid passive voice; use active voice
- Remove redundant words and phrases

**Inclusivity:**
- Use gender-neutral language
- Represent diverse perspectives
- Use accessible language for broad audiences
- Avoid cultural assumptions

**Consistency:**
- Use consistent terminology across all materials
- Standardize date formats, measurements, and units
- Use consistent heading styles and structures
- Maintain parallel grammar structures

**Examples:**

Weak: "Innovation is something that Valeo is committed to as a technology company."
Strong: "Valeo innovates to advance automotive technology."

Weak: "The Power Division brings together expertise in thermal management and powertrain systems."
Strong: "Power Division combines thermal management and powertrain expertise to accelerate electrification."

### Terminology Standards

**Approved Terms:**
- Valeo (not "Valeo Group" in first mention without context)
- Brain Division, Power Division, Light Division
- Software-Defined Vehicle (SDV)
- Advanced Driver Assistance Systems (ADAS)
- Electrification (not "going electric")
- Autonomous driving (not "self-driving")
- Mobility solutions (not "car products")
- Sustainable/Sustainability (not "eco-friendly")

**Terminology to Avoid:**
- "Green" (use "sustainable" instead)
- "Cutting-edge" (use "advanced" or "innovative")
- "Revolutionary" (overused; be specific)
- "Groundbreaking" (use specific technology names)
- "Latest and greatest" (unprofessional)

### Headline Guidelines

- Use strong action verbs
- Make headlines specific and benefit-focused
- Keep headlines concise (under 10 words when possible)
- Avoid question headlines unless necessary
- Capitalize major words (Title Case)

**Examples:**
- "Valeo's LiDAR Technology Powers Autonomous Driving"
- "48V Electrification: Affordable, Efficient, Accessible"
- "Advancing Safety Through Advanced Driver Assistance"

### Call-to-Action Guidelines

**Effective CTAs:**
- "Learn More About Our Solutions"
- "Explore Valeo's Innovation Hub"
- "Schedule a Product Demonstration"
- "Download Technical Specifications"
- "Join Our Team"

**CTA Best Practices:**
- Use first-person perspective ("Discover", "Explore", "Get")
- Be action-oriented and clear
- Create sense of value or benefit
- Use contrasting colors (Valeo Red)
- Place CTAs prominently

### Grammar & Punctuation

- Use Oxford comma in lists
- Use em dashes (—) instead of double hyphens
- Spell out numbers one through nine; use numerals for 10+
- Use contractions sparingly in formal communications
- Maintain parallel structure in lists and bullet points
- Use semicolons to connect related independent clauses

## BRAND APPLICATIONS

### Digital Applications

**Website:**
- Navigation: Use Valeo Dark Gray for primary navigation with Lime Green accents
- Headers: Use H1 and H2 with appropriate hierarchy
- Links: Use Accent Teal (#00A8A8)
- Buttons: Use Valeo Lime Green background with dark gray text
- Footer: Use dark gray or black background with white text
- Maintain responsive design for mobile devices

**Email Communications:**
- Header: Use logo with Valeo Lime Green accent background
- Body: Use 16px dark gray text on white background
- Links: Use Accent Teal underlined text
- CTAs: Use Valeo Lime Green button with dark gray text
- Signature: Include official Valeo branding

**Social Media:**
- Profile Banner: Use Valeo Dark Gray with Lime Green logo
- Post Graphics: Maintain consistent color palette with green as primary accent
- Typography: Use primary typeface (Inter or Roboto)
- Imagery: Use high-quality, authentic photographs
- Hashtags: #ValeoInnovation #SmartTechnology #SmarterMobility

**Presentations:**
- Title Slide: Use Valeo Dark Gray background with white text and Lime Green accents
- Section Headers: Use Valeo Lime Green accent bar
- Body Slides: Use white or light gray background with dark gray text
- Visuals: Include relevant technology imagery
- Footers: Include Valeo logo and page numbers

### Print Applications

**Business Cards:**
- Front: Valeo logo with contact information
- Colors: White background with Valeo Lime Green and Dark Gray
- Typography: Use Inter or Roboto 9pt for text
- Dimensions: Standard 3.5" x 2" (88mm x 51mm)

**Letterhead:**
- Header: Valeo logo positioned top-left with Lime Green accent
- Colors: Lime Green border or accent stripe with white background
- Typography: Official contact information in dark gray
- Paper: Premium white or off-white stock

**Brochures:**
- Cover: Bold imagery with Valeo logo and headline
- Interior: Use consistent grid layout
- Colors: Accent Valeo Lime Green and Dark Gray throughout
- Typography: Maintain hierarchy with clear headings
- Call-to-Action: Use Valeo Lime Green background

**Advertisements:**
- Headline: Bold, action-oriented messaging
- Visuals: High-quality product or innovation imagery
- Logo Placement: Bottom-right corner with clear space
- CTA: Prominent button or hyperlink in Lime Green
- Colors: Use full color palette with emphasis on primary Lime Green

### Signage & Environmental

**Building Signage:**
- Exterior: Use Valeo logo with Valeo Dark Gray background and Lime Green accents
- Interior Wayfinding: Use consistent arrow and typography with green highlights
- Office Nameplates: Use dark gray text on white/light background with green accent
- Color Coding: Use secondary colors for department identification

**Vehicle Wraps:**
- Primary Design: Valeo logo with product imagery
- Colors: Use Valeo Lime Green and Dark Gray with white accents
- Information: Include website and contact details
- Design: Ensure visibility and impact from distance

### Merchandise & Promotional Items

**Apparel:**
- Color: Valeo Dark Gray base with embroidered Lime Green logo
- Logo Size: Appropriate to garment type (typically 2-3 inches)
- Placement: Left chest, back neck, or sleeve
- Quality: Use premium materials and embroidery

**Promotional Items:**
- Logo Size: Scaled appropriately to item dimensions
- Color: Primary Lime Green and Dark Gray when possible
- Branding: Include Valeo logo and possibly tagline
- Quality: Professional production standards

## DO'S AND DON'TS

### DO

- ✓ Use official logo files provided by brand team
- ✓ Maintain consistent spacing and margins around logo
- ✓ Apply consistent typography hierarchy across all materials
- ✓ Use high-quality, authentic imagery and photography
- ✓ Ensure sufficient contrast for accessibility (WCAG AA minimum)
- ✓ Test all materials across different devices and browsers
- ✓ Use inclusive, professional language
- ✓ Align visual design with brand color palette
- ✓ Verify spelling, grammar, and technical accuracy
- ✓ Credit photographers and content sources appropriately
- ✓ Maintain brand consistency across all touchpoints
- ✓ Use active voice and clear, direct communication
- ✓ Test color combinations for color-blind accessibility
- ✓ Keep loading times and file sizes optimized
- ✓ Use official terminology and approved messaging

### DON'T

- ✗ Never modify, distort, or recreate the logo
- ✗ Don't use outdated logo versions
- ✗ Avoid placing logo without adequate clear space
- ✗ Don't use weak or low-resolution images
- ✗ Avoid excessive design effects or filters
- ✗ Don't mix multiple brand color palettes
- ✗ Avoid jargon-heavy or unclear messaging
- ✗ Don't use generic stock photography
- ✗ Avoid poor contrast between text and background
- ✗ Don't change brand colors without approval
- ✗ Avoid passive voice in headlines
- ✗ Don't use competing brand materials
- ✗ Avoid all-caps text (except for acronyms)
- ✗ Don't crowd designs with too many elements
- ✗ Avoid outdated design styles or trends
